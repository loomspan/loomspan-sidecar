## Findings

No open actionable findings after the fixes below.

### [P2] Make account version change and editing cleanup indivisible
- Location: `src/main/java/ai/loomspan/sidecar/management/ManagementIdentityService.java:128`
- Scenario: `redeem`, `change` or `alter` committed a new account version, then acquired the editing monitor to clear the account's old drafts. A new login using the new version could acquire a lease in that gap.
- Impact: Cleanup could then remove the new session's valid draft and grant immediately after acquisition, giving the client a capability that no longer existed.
- Evidence: The previous transaction and `editing.clearAccount` were separate critical sections; `ManagementEditingService.acquire` checks the current account version and enters the editing monitor. Existing account cleanup tests were sequential and could not detect this interleaving.
- Fix: Hold the editing monitor across each account-version transaction and its cleanup. Editing acquisition and publication transition already use that same monitor, so the new session cannot enter between commit and cleanup.

### [P2] Recheck login expiry when recording activity
- Location: `src/main/java/ai/loomspan/sidecar/management/ManagementSessionGuard.java:52`
- Scenario: A request could pass the session guard just before its 30-minute deadline, then be delayed until after the deadline before reaching `/session/activity` or `/editing/lease/activity`.
- Impact: The previous `report` method marked that expired session active again, and an editing report could renew its lease. This violated the explicit late-report requirement.
- Evidence: The request filter checked the deadline only at request admission, while the previous `report` checked only the 30-second report interval before calling `mark`. The existing HTTP late-report test started its request after expiry, so the filter rejected it before reaching `report`.
- Fix: Check the effective idle deadline again at report time, invalidate expired sessions, and use one captured timestamp for the deadline, throttle and new marks. A focused test exercises expiry after admission.
