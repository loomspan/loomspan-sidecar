  transport state machine, configuration or data reset was introduced.

  synthetic diagnostic values and check that unusable response and credential
  text do not appear in exceptions.

## Open Questions and Assumptions

None requiring a developer decision. The review uses transport invocation as
the boundary of possible dispatch. Once inside the transport, a failure alone
does not prove that the peer did not receive the POST. For reads, a transport
operation terminated by interruption or the explicit wait deadline retains the
existing wait exception and context.
