## Findings

No actionable findings.

`CallbackVerifier` verifies the original compact signing input against a
locally selected RSA public key and applies the exact profile and time checks
before returning identity. Optional dates are checked only when supplied.
The dedicated Decimal context preserves wire nanoseconds and prevents the
ambient application context from changing comparisons.

The trust worker reads and validates a complete candidate before changing
the event-loop-owned snapshot. Unknown-key requests can join one read and
the throttle is independent of supplied key IDs. A close clears current keys,
wakes waiters and discards any candidate still being read. Relative paths are
anchored before the initial read without resolving symlinks, so later reads
follow replacement at the configured pathname.
