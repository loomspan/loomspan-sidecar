  one optional module and no replacement authentication protocol, legacy API,
  new Framework extension contract or remote drain coordinator.

  role and record checks retain their authority. No SDK inference uses model
  inputs or browser session identity.
- Signer/export ownership and verifier refresh remain explicit. The only files
  written by verification were synthetic test files or isolated build artifacts.
  No development-data reset, operational key replacement or publication is needed.

  middleware placement limits. The installed example uses no paid provider and
  the runtime dependency extra has no server or CLI.
