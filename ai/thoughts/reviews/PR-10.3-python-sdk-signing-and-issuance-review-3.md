  configuration or runtime conversion interface. The extra ASN.1 checks preserve
  structural rejection and the tested BER forms. Arbitrary unused attribute
  payload semantics remain with the libraries as approved.
- Identity enters through the explicit authentication snapshot. Neither client
  acquires an implicit current identity or receives raw signing material.
- Both Java tests stay in Sidecar or SDK code and use no Loomspan Framework
  internals. The Sidecar test uses the installed Framework snapshot through its
  usual Maven build. No operational key, deployment, or persisted data changed.
- The README describes current behavior and operator responsibilities without
  adding release, migration, or future delivery instructions.
