## Findings

### [P2] Use the deployed Compose project in recovery commands

- Location: `README.md:214` and `README.md:260`
- Scenario: An operator follows the production guide's `--project-name production` startup and then follows the root README's stopped-instance backup or recovery procedure. Its `stop` and `start` commands omitted that project name.
- Impact: Compose targets its default project instead of the running `production` service. The operator could back up or replace the database while the actual Sidecar is still running, making the stopped-instance copy unsafe.
- Evidence: `examples/production/README.md` starts, recreates, and names volume `production_sidecar-data` under project `production`; the original root README stop/start commands had no matching project option.
- Fix: Added `--project-name production` to both root README commands.
