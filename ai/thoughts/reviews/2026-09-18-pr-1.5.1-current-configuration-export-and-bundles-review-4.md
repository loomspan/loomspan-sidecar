## Findings

### [P3] Enforce the documented source UUID shape
- Location: `src/main/java/ai/loomspan/sidecar/bundle/ConfigurationBundleV1.java:295`
- Scenario: A manifest contains `"sourceSnapshotId":"1-1-1-1-1"` with otherwise valid entries and digests.
- Impact: The reader accepts a manifest that violates the documented format 1 UUID schema and silently normalizes provenance.
- Evidence: Java `UUID.fromString` accepts shortened groups; the new targeted test failed before the fix because no exception was raised.
- Fix: Require eight-four-four-four-twelve hexadecimal groups before parsing; add the malformed-ID regression case.

## Findings Resolved in This Context

- Applied the UUID shape check and regression test. Re-read the modified method and the surrounding manifest validation after the fix; no further actionable issue was found.
