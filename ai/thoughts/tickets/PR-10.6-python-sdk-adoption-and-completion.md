# PR 10.6: Adopt the Python SDK in the maintained suite and prove the complete release target

## Development constraints

**Sidecar is still in development. Destructively replace superseded contracts,
code and schemas; no compatibility shims, legacy adapters, parallel legacy APIs
or migration machinery solely to preserve obsolete development behavior.**

Apply the [design lens](../design-lens.md#simplicity-and-technical-debt). Choose the
simplest complete solution and minimize technical debt. Keep implementation,
tests and documentation proportional. No data reset is expected; preserve existing
credentials, identities, operational data and reference packs. Document any newly
required development-data reset and its impact; this is not permission to delete
deployed data or regenerate operator keys.

## Outcome

Replace the maintained Python application's custom Sidecar transport/JWT glue with
the completed SDK and demonstrate preserved business behavior, Java/Python parity
and the agreed installed-package support targets before the series is ready to sync.
