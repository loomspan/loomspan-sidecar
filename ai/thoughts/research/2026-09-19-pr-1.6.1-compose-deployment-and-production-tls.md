# Compose Deployment and Production TLS Research

## Research Question

What packaging, deployment instructions, application contracts, and executable evidence currently exist for the ticket's single-instance Compose deployment and HTTPS console?

## Summary

The checked-in image runs as UID/GID `10001:10001`, but the only Compose file is a deterministic HTTP quickstart with a fixture issuer/model host. Its named SQLite volume persists `/sidecar/data`; it publishes application and health ports to the host and supplies no production TLS endpoint. The image verifier exercises that quickstart, not production TLS, account persistence, or SMTP. The application already contains database-first activation, separate management session and JWT execution security, configured email-link origins, strict REST URL variable binding, readiness/liveness, and shutdown gates. The deployment-specific integration evidence requested by this ticket is not yet present.
