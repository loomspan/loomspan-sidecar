# Managed Sidecar installation variables testing plan

## Change Summary

Prove authored documents are preserved, Framework validation precedes value lookup, and the same exact explicit variable map drives detached validation, publication and restoration. Exercise the HTTP generation boundary, write-only managed values, current-value rollback, startup modes and affected external fixtures.

## Impacted Areas and Risks

| Category | Risk | Planned evidence |
| --- | --- | --- |
| YAML discovery | Lost complex keys, overbroad marker recognition or selector lookups | Node tests with map key/value, sequence, selector, and exact-name fixtures |
| Management validation | Wrong revision or credential lookup masks structural errors | Framework/public API validation with counted lookup and real editing calls |
| Confidentiality and portability | Resolved values show up in management output, bundle entries or diagnostics | Authorized HTTP reads, ZIP inspection, ciphertext query and safe error checks |
| Publication | Mixed values and routes, early application of draft edits or historical key revival | Receiver, old dispatch handoff, restarts, explicit removal/repair |
| Deployment authority | Managed startup reads file providers, or file mode fails after Framework startup | Existing mode suite and external mounted fixture packs |
