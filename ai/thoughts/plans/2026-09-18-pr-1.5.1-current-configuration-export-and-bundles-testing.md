# Current Configuration Export Testing Plan

## Change Summary
Add format 1 ZIP export, reader, management download, and console control.

## Impacted Areas and Risks
| Category | Risk | Planned evidence |
| --- | --- | --- |
| Runtime | Export follows intended pointer or mixed publication | captured runtime identity/content test |
| ZIP | Ambiguous, corrupt, unsafe, oversized archive | reader negative matrix and boundary tests |
