## Current State

`SkillCatalogController` and `ExecutionController` already expose the authenticated
execution routes. Java `SidecarClient` owns the reference HTTP status, UUID, model
validation, credential, deadlines, and polling behavior. `sdks/java` is the only
existing SDK package. The starting checkout was clean at `b4701c270415430c960697579bdbbd9e260570fe`.
The untracked research artifact belongs to this pipeline.

## Desired End State

Install `loomspan-sdk` 0.1.0.dev0 and import `loomspan_sdk` without Sidecar, Java,
web dependencies, or signing facilities. An existing per-call execution credential
can discover, submit, read status, and wait against a configured HTTP(S) endpoint.
Callers receive typed snapshots with exact result text and available diagnostics.
Failure categories distinguish validation, observed HTTP status, invalid read
responses and uncertain acceptance. Local timeout, interruption, and close release
local HTTP resources and leave the server execution lifecycle with Sidecar.

## Scope

### In scope

- Standalone Python core package, synchronous client and focused local tests.
- Transport-independent models, credentials, URL/JSON validation and error policy
  available internally to the async implementation.

### Out of scope

- Async transport, issuance, callback trust, FastAPI, maintained-suite adoption,

## Active Project Guardrails

**Replace obsolete development contracts directly.** Apply the
[design lens](../design-lens.md#simplicity-and-technical-debt). No replacement or
development-data reset is needed. Keep identity outside business payloads,
diagnostic content faithful, and transport credentials out of default output.
Use the Sidecar HTTP API, keep consumer docs about executable current behavior, and
leave certificate issuance, trust provisioning and lifecycle to operators.

## Impact and Risk Analysis

- A per-read timeout alone lets a trickling peer prolong a request. Deadline checks
  must run before every blocking operation and through buffered event processing.
- Once submission has entered the transport dispatch path, the SDK cannot infer an
  acceptance ID from transport behavior. An observed final non-2xx status survives
  body overflow, malformed/truncated bodies, and timeout while reading its body.
- Concurrent calls cannot share bearer or cookie state. Close can race with DNS,
  socket creation, wrapping for TLS, and response reads. Ownership of the live
  socket and its cleanup must be explicit.
- JSON decoder or HTTP parser exceptions may contain server data or the outgoing
  Authorization header. Public exceptions need fresh safe state and no retained
  low-level exception context. Business output is a separate content boundary.
- Built artifacts and consumer type checking are independent of in-tree imports.

## Implementation Approach

Use a small private synchronous adapter over standard `socket`/`ssl` and public
`h11` HTTP/1.1 framing. Use one connection per operation, with no pooling or
additional transport extension contract. h11 owns framing and parses both
fixed-length and chunked bodies. The SDK owns deadlines, byte limits, one request
per connection, closure, and public result/error policy. Research demonstrated
real peer-side release for stalled and trickling reads on Windows. HTTPX's sync
timeouts bound individual operations and its public interface lacks this whole
exchange deadline. A timed join would leave I/O running. libcurl offers a native
transfer deadline but does not accept Python `SSLContext` for the required trust
and client identity configuration. A new HTTP parser or private event loop would
add avoidable ownership. See the [h11 event API](https://h11.readthedocs.io/en/stable/api.html)
and [Python socket timeouts](https://docs.python.org/3/library/socket.html#notes-on-socket-timeouts).

System DNS is the same distinct boundary as in the Java baseline. Use ordinary
synchronous `getaddrinfo` and charge its elapsed time to connect/exchange budgets.
The OS resolver itself is synchronous and lacks portable in-process cancellation.
Recheck the budget and client state after lookup, before opening any connection.
Describe that distinction explicitly in the SDK README. Keep actual TCP, TLS,
upload, headers and body I/O bounded. Trying another resolved address after TCP
connect fails before writing HTTP is address selection, with one shared connect
deadline and a single HTTP request. There is no retry after transport writes.

Distinguish local preparation/validation from an attempted exchange. Match Java's
conservative classification of transport errors after dispatch starts, including
connection failures for submit. A client closed before dispatch or rejected
local input raises `LocalFailure`. Discovery/status transport or response failure
raises `ProtocolFailure`. For submit, a transport or unusable success response
after dispatch raises `AcceptanceUnknown`. Any observed final non-2xx takes
precedence and raises `HttpFailure`; the ticket's observed-status requirement
also applies if a wait budget expires while consuming that error body. Without
such a status, a read cut off by its wait deadline raises `WaitTerminated`.

  project metadata with name `loomspan-sdk`, version `0.1.0.dev0`, Python
  `>=3.12`, README, Apache-2.0 license, direct `h11>=0.16,<0.17`, and wheel
  src-layout selection. Include the repository's Apache-2.0 license text in the
  package's independent source distribution via `sdks/python/LICENSE`.
- [x] `sdks/python/requirements-dev.txt` — pin `pytest==9.0.2`,
  `trustme==1.2.1` for synthetic TLS test fixtures, and `mypy==1.20.0` for
  installed consumer type checking. All three tools and h11 0.16.0 were resolved
  in a disposable Windows CPython 3.13.13 environment. Runtime uses h11 only.
- [x] `sdks/python/src/loomspan_sdk/__init__.py` and `py.typed` — explicitly export
  the public types and package the typing marker. Keep the remaining transport
  and decoding policy private.
- [x] `sdks/python/src/loomspan_sdk/_models.py` — frozen typed `SkillDescriptor`,
  `AcceptedExecution`, `ExecutionSnapshot`, `ExecutionStatus`, `ExecutionFailure`,
  `ExecutionIssue`, `ExecutionEvent`, and `WaitOptions`. Use `UUID` for IDs,
  tuple containers for arrays of records, and `None` for unavailable optional
  fields. Copy nested event details on ingress and each public access. Preserve
  the original validated ISO instant string to retain nanoseconds and extended
  year values without silently narrowing through Python `datetime`. Status is
  a string enum with terminal state derived solely from COMPLETED or FAILED.
  `WaitOptions` defaults to 60 s and 0.25 s; use shared finite positive duration
  validation and guard against values beyond the platform-representable limit.
- [x] `sdks/python/src/loomspan_sdk/_credential.py` — `CredentialSnapshot(token)`
  accepts printable ASCII `0x21..0x7E`, rejects other values with a safe error,
  and stores the token privately. Give it fixed redacted `repr`/`str`, no public
  token getter, and block pickle/state serialization. Only internal Authorization
  construction and textual problem redaction access the token.
- [x] `sdks/python/src/loomspan_sdk/_errors.py` — public `SidecarError`,
  `LocalFailure`, `HttpFailure`, `ProtocolFailure`, `AcceptanceUnknown`, and
  `WaitTerminated`. Status/wait context includes `execution_id` and
  `last_snapshot`. HTTP failures additionally expose `status_code` and a
  defensive copy of optional redacted `problem`. Use fixed messages and raise
  outside low-level exception handlers so `__context__` does not retain parser
  input, raw error bodies or outgoing request credentials.
- [x] `sdks/python/src/loomspan_sdk/_protocol.py` — own validated origin/base-path
  and request targets, object encoding, strict JSON decoding, parsers and shared
  response policy. Reject malformed or non-HTTP(S) base URLs and userinfo/query/
  fragment, including empty `?` or `#` markers. Preserve encoded base-path
  characters and quote accepted UTF-8 skill names into a single segment. Match
  Java's whitespace and C0/C1 control rules, rejecting slash, backslash, percent,
  and whole `.`/`..` names. Require compact canonical-shape UUID text from wire
  (hyphenated and case-insensitive), preserve actual descriptor name, validate
  status ID equality and construct status URLs locally. Validate dictionary JSON
  inputs before sending, including nested keys/values, rejecting non-string keys,
  cycles, and nonfinite numbers rather than silently coercing them. Reject
  duplicate names at every JSON object depth, nonstandard numeric constants,
  trailing tokens, and malformed known required/optional fields while ignoring
  additive fields. For instants, validate lexical ISO instant, calendar, time,
  and offset while retaining exact text. Java `Instant.parse` supports nanosecond
  fractions, extended years, zero-fraction 24:00, and leap-second spelling.
  Tests should cover representative forms and a malformed calendar date. Avoid
  adding a standalone temporal type or a business-schema interpreter.
- [x] `sdks/python/src/loomspan_sdk/_protocol.py` — classify 202-only acceptance
  and 200-only reads, observed HTTP failures, deadline failures and read/submit
  protocol errors. Decode optional error problems only from complete bounded
  objects. Redact credentials recursively in string values and keys using a
  replacement which cannot itself contain the printable-ASCII token. Withhold
  the optional object if redaction collides with an existing key. Keep the
  requested status UUID and wait snapshot on all SDK errors where available.

## Phase 2: Implement the blocking exchange and polling lifecycle

### Changes

- [x] `sdks/python/src/loomspan_sdk/_sync_transport.py` — one private exchange
  implementation with h11 request/data/end events, `Host`, `Accept`, request-local
  `Authorization`, JSON `Content-Type` and `Content-Length` for POST, and
  `Connection: close`. No compression advertisement or content decoding, cookie
  state, environment proxy, redirect, or challenge handling. Use absolute
  monotonic exchange deadline and an earlier connect deadline, both constrained by
  a wait deadline when present. Set remaining socket timeout before connect, TLS
  handshake, every partial `send` and each `recv`. The explicit send loop keeps
  the same absolute budget through partial writes on both plain and SSL sockets.
  Recheck between parsing events and before recognizing a complete success. A
  default HTTPS context verifies certificates
  and hostnames. Allow caller-provided standard verifying SSL contexts, retaining
  CA and client identity without changing context settings. Reject non-verifying
  contexts for HTTPS. Use the hostname for SNI and certificate checking. Keep
  context configuration stable while in use and handle only HTTP/1.1.
- [x] `sdks/python/src/loomspan_sdk/_sync_transport.py` — capture final h11
  response status immediately and stop processing only after complete framing or
  on a classified failure. Bound incomplete framing with h11's configured size
  and read in bounded chunks. Reject oversized declared lengths early and track
  actual decoded transfer bytes, including lengthless and chunked streams. Close
  incomplete connections without drain. Handle ordinary informational responses
  without mistaking them for final success; no protocol upgrade.
- [x] `sdks/python/src/loomspan_sdk/_sync_transport.py` — register each active
  socket under a lock before I/O; coordinate replacement of the raw socket by its
  TLS wrapper under the lock with handshake disabled during wrapping. The request
  owns final close/deregistration in `finally`. `close` marks the client closed,
  rejects subsequent registration, and shuts down active sockets to release
  connected I/O without joining threads or draining. Use plain socket shutdown on
  TLS sockets to abort I/O without a TLS shutdown exchange. The same cleanup
  applies when `KeyboardInterrupt` leaves a request. Do not catch `BaseException`
  for classification or install an interruption adapter.
- [x] `sdks/python/src/loomspan_sdk/_client.py` — `SidecarClient(base_url, *,
  connect_timeout=2.0, response_timeout=10.0, max_response_size=8*1024*1024,
  ssl_context=None)`, `close`, context management, `list_skills`, `get_skill`,
  `submit`, `get_execution`, `wait_for_completion`. Use one private status read
  path with requested UUID and optional wait context. Compute a single wait
  deadline, bound each read and sleep, and update the last snapshot only after a
  valid read. Return on COMPLETED/FAILED, poll QUEUED/RUNNING, and stop at the
  first SDK read error. Native `KeyboardInterrupt` propagates from I/O or sleep.
  Local termination issues no remote cancellation or retry. Move only truly
  reusable URL, options, protocol, model, and error policy into shared helpers.

## Test Strategy

Use pure parser/model cases for validation and defensive copies, a loopback wire
fixture for behaviors whose correctness depends on transport, synthetic TLS for
private CA/hostname/client identity, and isolated processes for install and example
behavior. Verify server-side connection release after error/timeout/interruption
and use request counters to prove no replay. Java source and tests establish the
reference contract. Python tests provide the new implementation evidence.

## Risks and Rollback/Recovery

No Sidecar behavior, deployment state or operational data changes. The package
is additive, so rollback removes the isolated package and its documentation link.
If TCP/TLS/socket cleanup cannot be proven with the proposed public facilities on
a target platform, preserve the evidence and escalate any necessary contract or
support change. PR 10.6 owns final combined evidence, including unavailable platform
checks explicitly recorded here during implementation.
